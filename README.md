# F1 championship break-even

Local-only Formula 1 standings, remaining races, and an interactive championship clinch calculator using official F1 data.

```sh
npm run setup
npm run dev
```

Requires Node.js 24+. Open http://127.0.0.1:5173. The server binds only to loopback. No deployment or cloud hosting configuration is included.

See [the app README](site/README.md) for source details, caching, calculation assumptions, and tests.
